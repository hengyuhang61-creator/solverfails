# Contribute a case

Open a [case suggestion](https://github.com/hengyuhang61-creator/solverfails/issues/new?template=case.md). A public issue URL, redistributable fixture, minimal command or correction to an existing label is enough to start. Include the accepted claim, the signal that passed, and what observation might contradict it. If the pass is hypothetical, label the example simulated.

Maintainers can help minimize the replay, add a passing control and document what is still unknown. Accepted cases link the original record and credit the contributor by the name or handle they choose. Corrections to source identity, scope or oracle labels are welcome. A contribution can also demonstrate a false rejection or a failure of the revised check.

Only share material you have permission to publish. Link third-party data when redistribution rights are unclear. Leave out confidential research, personal information, credentials and private logs. For a citation, use GitHub’s “Cite this repository” entry and identify the case and exact revision.
